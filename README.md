# Projeto 'Demi Lovato' 

Projeto realizado para finalização do módulo 'Desenvolvimento Web' do curso de _informática_ da Microcamp Barueri.

O projeto teve por finalidade aplicar o que aprendido de HTML5 e CSS no módulo.
Foram ultilizados:


## Escolha do tema

O tema escolhido foi por que eu sigo uma famosa, e ela admira muito a Demi, eu também mais não escuto muito. Mais gosto dela uma das musicas da Demi que eu escuto é 'Heart Attack' lançada em 2013.

## Escolha do Layout (fonte e paleta de cores)

As cores escolhidas foram selecionas do site _color hunt_. Escolhi a paleta por que as cores combinam com a cantoran, e a fonte também achei que combina muito com ela. (minha opinião).
Cores: [https://colorhunt.co/palette/15173d982598e491c9f1e9e9]
Fonte: [https://fonts.google.com/specimen/Tangerine?query=Toshi+Omagari&preview.script=Latn].

## O que eu aprendi

Eu aprendi várias coisas nesse módulo, como criar tabelas, adicionar imagens, músicas etc. Também aprendi como colocar fontes, cores, fiz tudo isso sem o uso de Inteligencia Artificial (IA). Levei 3 meses e meio para concluir esse site. Gostei muito da experiência de ter meu primeiro site no ar, demorou alguns meses para ser feito, mais valeu cada aula.
